# 历史会话补充证据

用户要求“回顾最近的项目”“整理之前的经验”等时，按明确的工作区与时间范围执行，无需专门的授权按钮，也不以已建立画像为前提。普通任务中的知识维护不自动授权扫描历史；不主动定期邀请整理。

1. 已有项目规则和 Memory 优先。根据用户目标与范围先看会话元信息；未指定时间时从近期相关、已完成会话开始，并说明采用的范围。
2. 第一批选择至多 3 个高信号会话，按需读取摘要或局部片段。已归档不代表内容无效；不全量读取原始 JSONL，不跨工作区扩展搜索。
3. 证据足够即停止。确需更多时在用户已指定范围内继续小批读取；超出范围须先确认。区分历史结论与当前事实，对可能过时的内容按需要重新核验。
4. 按 Coach 的知识维护规则，把有长期价值的经验写入相关 Memory 主题，标注必要时间并更新索引。项目事实更新项目地图，临时过程不升级为长期知识。
5. 报告实际查看的范围、得到的结论与写入位置。没有足够证据时如实说明，不为产生记忆而推断。
